# Support

## How to file issues and get help

Copilot Managed Runtime uses GitHub Issues to track bugs. Please search the existing issues before
filing new issues to avoid duplicates. For new issues, file your bug as a new Issue in this
repository.

For how-to questions and product guidance, see the [Copilot Managed Runtime documentation](https://go.microsoft.com/fwlink/?LinkId=2369054).

## Microsoft Support Policy

Copilot Managed Runtime is currently in **public preview**. Support is limited to the resources
listed above.
