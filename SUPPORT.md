# Support

## How to file issues and get help

Microsoft Managed Apps has moved to [Copilot Managed Runtime](https://github.com/microsoft/Copilot-Managed-Runtime).
Please [search the CMR issue tracker](https://github.com/microsoft/Copilot-Managed-Runtime/issues)
before filing new issues to avoid duplicates, and check the historical issues here if relevant.
File new bugs in [the CMR repository](https://github.com/microsoft/Copilot-Managed-Runtime/issues/new/choose),
not this repository.

Maintainers will transfer existing open issues with their discussion history and keep them open
for continued triage. You do not need to resubmit your report. After transfer, the original issue
URL will redirect to its new location. Closed issues remain in this repository for reference.
Watch the CMR repository if you want updates about activity there.

For how-to questions and product guidance, see the [Microsoft Managed Apps documentation](https://go.microsoft.com/fwlink/?LinkId=2369054).

## Microsoft Support Policy

Microsoft Managed Apps is currently in **public preview**. Support is limited to the resources
listed above.
